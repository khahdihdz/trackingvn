# TrackingVN

Website tra cứu mã vận đơn Việt Nam, mobile-first và triển khai tĩnh trên GitHub Pages.

- Tự động nhận diện định dạng mã.
- Hỗ trợ SPX Express, GHN, GHTK và Viettel Post.
- Không giả lập trạng thái hoặc vị trí.
- Mở hệ thống chính thức khi cần dữ liệu thật.
- Lịch sử chỉ lưu trong localStorage.
- Không chứa API key/token merchant.

Chạy local: npm ci && npm run dev
Build: npm run build

GitHub Pages: Settings → Pages → GitHub Actions.
